# FUSBALL_FPGA
FPGA-based Foosball game implemented in SystemVerilog and synthesized using Intel Quartus, including RTL design, simulation, and hardware deployment.

## Features
- Real-time input handling
- FPGA implementation using RTL design
- Modular SystemVerilog architecture
- Simulation and hardware verification on FPGA board

## Tools
- SystemVerilog
- Intel Quartus
- FPGA Development Board
- ModelSim (simulation)

## FPGA Implementation
The design was synthesized and deployed on FPGA hardware, demonstrating real-time digital system behavior.
